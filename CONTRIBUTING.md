# Contributing to Hamrah Academy Prompt Engineering Workshop

Thank you for your interest in contributing! We welcome all types of contributions.

## 🤝 How to Contribute

### Report Bugs
- Use GitHub Issues to report bugs
- Include clear description and steps to reproduce
- Add code examples and error messages

### Suggest Enhancements
- Open an issue with the tag `enhancement`
- Describe your idea clearly
- Explain why it would be useful

### Add New Content
- Create new tutorial notebooks
- Improve existing documentation
- Add practical examples

## 📝 Contribution Process

1. **Fork the repository**
   ```bash
   git clone https://github.com/YOUR_USERNAME/hamrah_academy_prompt_engineering_workshop.git
   ```

2. **Create a feature branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make your changes**
   - Keep commits clear and descriptive
   - Follow the existing code style
   - Add docstrings to functions

4. **Test your changes**
   - Run notebooks to ensure they work
   - Check for errors and clear output

5. **Commit and push**
   ```bash
   git add .
   git commit -m "Add description of changes"
   git push origin feature/your-feature-name
   ```

6. **Open a Pull Request**
   - Write a clear PR description
   - Reference any related issues
   - Wait for review

## 📋 Guidelines

### Notebook Guidelines
- Add clear section headers
- Include markdown explanations
- Add comments to code
- Show example outputs
- Keep notebooks focused on one topic

### Documentation Guidelines
- Use clear, simple language
- Include examples where applicable
- Link to relevant resources
- Keep formatting consistent

### Code Style
- Follow PEP 8
- Use meaningful variable names
- Add comments for complex logic
- Keep functions small and focused

## 🎯 What We're Looking For

- New tutorial notebooks on prompt engineering topics
- Improvements to existing documentation
- Real-world use cases and examples
- Bug fixes and error handling
- Translation contributions (especially Persian!)

## ⚖️ Code of Conduct

Be respectful and constructive. We're building a welcoming community for all learners.

## 📧 Questions?

Open an issue or reach out to the maintainers. We're here to help!
